3 Dashboard & Reports

Dashboard

Shows real-time KPIs pulled from actual transaction data — not hardcoded numbers.

  • Today Revenue: Sum of all transactions created today
  • Monthly trend chart: Last 6 months of transaction revenue, grouped by month
  • Date filter: Use the "From" and "To" date pickers in the top-right to filter the chart. Click Clear to reset.
  • Active Locations / Queue Waiting / Loyalty Members: Live counts from DB

Daily Report

Go to Daily Report in the left sidebar. Select a location and date. Shows POS sessions, revenue, therapist activity, and service breakdown for that day.

Data History

Under Config → Data History. Export any module to Excel, or import historical Excel data. Use the provided historical_data.json for initial seeding.

4 POS — Point of Sale

1
Select LocationUse the dropdown at the top of the screen. Your assigned locations appear here.
2
Open a SessionClick "New POS Session" and select the therapist on duty.
3
Add ServicesBrowse the service catalog. Click a service to add it to the cart. Services come from Config → Services.
4
Apply Discount (if any)Bulk discounts set by admin auto-apply. Manual discount can be entered in the cart.
5
Select Payment MethodCash / UPI / Card / Wallet. UPI shows QR code. Enter amount received.
6
Complete TransactionClick "Complete Sale". Transaction is saved to DB and synced to Drive.

Loyalty Redemption in POS

If customer's mobile is entered, their loyalty points appear. Click "Redeem Points" to apply as discount. Redemption rate is set in Config → Loyalty.

5 Token Queue System

Manages walk-in queues at each kiosk location.

  • Issue Token: Click "+ New Token" → select service → assign therapist → print/display token number
  • Call Next: Click "Call Next" to advance the queue. The ESP32 display updates if connected.
  • Mark Complete: Click ✓ on a token when service is done
  • arama-qr.html: Customer-facing QR page. Customer scans QR at kiosk, joins queue on their phone, and gets real-time wait time.

6 Locations Management

Admin can manage all 33 locations (14 Gujarat + 16 Mumbai WR + 3 Vendor).

Actions in Locations page

  • View Details: Click on any location row to see full info
  • Edit: Update name, address, manager, contact, capacity, ESP32 IP
  • Activate / Deactivate: The red "Deactivate" or green "Activate" toggle button switches location status. Inactive locations do not appear in POS dropdown.
  • Add Location: Click "+ Add Location" to add a new kiosk
ℹ Location data includes: code, name, city, address, manager, phone, capacity, ESP32 IP, and active status.

7 Users & Roles Management

Active Users Tab

  • Edit: Update name, role, phone, email, locations, and password
  • Reset Pwd: Enter a new password — it shows in a modal for you to share
  • Deactivate: Soft-deactivates user (data preserved). Moves to Inactive tab.
  • Delete (Superadmin only): Permanently removes user. Cannot be undone.

Inactive Users Tab

  • Reactivate: Restores the user's access
  • Delete (Superadmin only): Permanently removes

Pending Approval Tab

  • Shows staff who registered via staff-register.html
  • Approve: Creates user account, shows temp password in modal
  • Reject: Removes from queue

Add User Manually

Click "+ Add User" at top. Fill name, username, password, role, phone, email, and assigned locations. Click Add User.

⚠ Roles higher than your own cannot be assigned. Only superadmin can create other superadmins.

8 HRMS — Staff Compliance

Track health certifications, training, and compliance for each staff member.

  • Health Card: Mark as valid / expired. Set expiry date.
  • First Aid Training: Track completion status
  • Hygiene Certification: Track status
  • Alerts: Expired or missing compliance items are highlighted in red

Go to HRMS → select a staff member → update their compliance record → Save.

9 Inventory / ERP

  • Products: Add consumables, oils, towels etc. with quantity and unit cost
  • Low Stock Alert: Items below minimum quantity are flagged
  • Purchase Orders: Create PO for vendor restocking
  • Vendor tab: List of approved vendors with contact info

All inventory data syncs to Google Drive with the rest of the DB.

10 Config — Services, Loyalty, Branding

Services & Pricing

  • Edit price, duration, description of each service
  • Bulk Discount Publisher: Set a % discount across all services for a date range. Click Preview → Confirm to apply.
  • Remove bulk discount with "Remove Discount" button

Loyalty Settings

  • Points per rupee spent (e.g. 1 point per ₹10)
  • Redemption rate (e.g. 100 points = ₹10 off)
  • Min points to redeem
  • Expiry period in months

Brand Config

  • Business name, tagline, support email/phone
  • App accent color
  • GST number, address

Drive Sync

  • Paste your Google Client ID (from GCP setup)
  • Click "Connect Google Drive" → authorize → all data auto-syncs every 6 seconds
  • Use the GCP_Drive_Setup_Guide.pdf for one-time Google setup under aramaasia@gmail.com

Data History / Excel Import

  • Export any module to Excel (.xlsx)
  • Import Excel file — preview data, then confirm import
  • Supported sheets: transactions, customers, services, locations, users, leads
